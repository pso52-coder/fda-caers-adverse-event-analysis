## 2. 역할표와 실제 수행의 간극

### 문서에 기재된 것

역할표의 본인 항목은 **운영·관리 업무로만 구성**돼 있습니다.

- 일정 관리 · 역할 조율 · 회의 진행 · 튜터 커뮤니케이션 · 최종 제출물 점검

전처리는 팀원 A, 시각화는 팀원 B, 해석은 팀원 C에게 각각 배정돼 있습니다.

### 문서에 기재되지 않은 것

**본인 진술에 따른 실제 수행 범위입니다.**

**① 발표 수행 및 발표 자료 전반 개입**

> 발표 담당이었으며, 발표용 PPT 전반에 관여했다.

**② 브랜드 사례 심층 분석** — 보고서 「04 수행 경과」의 옥시엘리트프로·하이드록시컷 2개 항목과 참고문헌 페이지

수행 경위는 다음과 같습니다.

> 팀의 데이터 분석 단계가 끝난 뒤 개인적으로 추가 진행한 작업이며, 결과물만 발표 자료와 보고서에 반영되고 **역할표에는 반영되지 않았다.**

작업 절차는 네 단계입니다.

1. 심각 부작용 신고가 많은 브랜드를 추림
2. 해당 브랜드의 **연도별 신고 건수 추이** 확인
3. 추이에서 신고가 특별히 많았던 **시기를 추정**
4. 그 시기에 실제 문제가 있었는지 **보도자료·외부 자료와 대조**

### 역할표와의 정합성 확인

역할표는 팀원 D를 "문서 정리 및 PPT 작성 — 결과보고서 PPT 작성, **발표 흐름 구성, 발표 대본 및 리허설 정리**"로 기재하고 있습니다.

**실제 분담은 다음과 같습니다.** (본인 확인)

| 항목 | 실제 담당 | 역할표 기재 |
|---|---|---|
| PPT 제작 | 팀원 D | 팀원 D (일치) |
| 발표 영상 제작 | 팀원 B | 기재 없음 |
| **발표회 발표 수행** | **본인** | 팀원 D 항목에 흡수 |

제출물에 발표 영상이 포함되는 과제였고, 실제 발표회는 별도로 진행됐습니다. 영상 제작과 발표회 발표가 서로 다른 사람이었는데, 역할표에는 발표 관련 항목이 PPT 담당자에게 일괄 기재됐습니다.

**서술 시 구분**

| 구분 | 서술 |
|---|---|
| 사용 | "발표회 발표를 담당했고, 사례 분석 파트를 구성했다" |
| 피할 것 | "발표 자료를 제작했다" (PPT 제작은 팀원 D) |

발표 자료 **제작**과 발표 **수행**은 다른 일입니다. 사례 심층 분석 내용을 직접 작성해 자료에 반영한 것은 "구성 참여"로 설명됩니다.

### 산출물 확인 **[문서로 확인됨]**

작성자 표기는 없으나, 해당 작업의 결과물은 문서에 남아 있습니다.

| 산출물 | 위치 | 확인 |
|---|---|---|
| 사례 심층 분석 — 옥시엘리트프로 | 결과보고서 「04 수행 경과」 | 최종·수정전 양쪽 수록 |
| 사례 심층 분석 — 하이드록시컷 | 결과보고서 「04 수행 경과」 | 최종·수정전 양쪽 수록 |
| 브랜드별 연도별 신고 추이 그래프 | 발표용 PPT | 수록 |
| 외부 자료 대조 서술 | 발표용 PPT (보고서보다 상세) | TGA·Health Canada·FDA 조치 시점 명시 |

> 옥시엘리트 프로는 2011년 7월 8일 호주 의약품관리국(TGA)에서 요힘빈 성분이 검출된 것을 확인하고 리콜 조치를 하였으며, 해당 년도 10월에는 캐나다보건부에서 섭취 중단을 요청… 2011년 12월 13일 한국소비자원 안전주의보 발령

### 노트북 구조상의 제약

제출된 코드는 `4조_팀프로젝트_코드.ipynb` **단일 파일 20셀**이며, 셀 단위 작성자 표기가 없습니다. **코드만으로는 누가 어느 셀을 작성했는지 판별할 수 없습니다.**

또한 **사례 심층 분석에 사용된 코드는 제출본에 포함돼 있지 않습니다.** 브랜드별 연도별 추이를 그리는 셀이 노트북에 존재하지 않습니다. 분석 단계 종료 후 별도로 수행했다는 진술과 일치합니다.

### 주장 근거의 성격에 대해

사례 심층 분석의 담당자 표기는 문서에 없으며, **본인 진술에 근거**합니다. 다만 이는 실무에서 흔한 상황이며 문제가 되지 않습니다.

- 팀 보고서의 역할표는 프로젝트 **시작 시점의 배정**을 적은 것이고, 진행 중 추가된 작업까지 갱신되는 경우는 드뭅니다
- 산출물 자체는 문서에 명확히 남아 있습니다 (보고서 2페이지 + PPT + 참고문헌 4건)
- 다른 팀원의 담당 범위와 겹치지 않습니다
- 면접에서 검증되는 것은 문서의 이름 표기가 아니라 **그 분석을 설명할 수 있는가**입니다. 브랜드를 왜 그 기준으로 골랐는지, 추이에서 무엇을 보고 시기를 특정했는지, 대조한 자료가 무엇이었는지 답할 수 있으면 충분합니다

**단, 역할표에 없는 내용을 주장하므로 서술은 정확해야 합니다.** 과장하면 검증 시 오히려 불리해집니다.

## 4. 권고

### 저장소 구성 방향

**"개인 사례 분석 + 재현·검증"** 두 축으로 구성하는 것을 권합니다.

앞서 정보가 부족했을 때는 "재현·검증 관점"만 제안했으나, 사례 심층 분석이 개인 작업이라면 그것이 **이 프로젝트에서 가장 내세울 만한 성과**입니다. 이유는 세 가지입니다.

**첫째, 팀 분석보다 한 단계 위의 작업입니다.** 팀 분석은 데이터 안에서 끝나지만, 이 작업은 데이터에서 시기를 특정하고 **데이터 밖의 사실과 대조**해 검증했습니다. 자발신고 데이터를 다루는 올바른 방법이기도 합니다.

**둘째, 지시받지 않은 일을 스스로 했습니다.** 역할표에 없고 분석 단계가 끝난 뒤에 진행한 작업입니다. 이 점을 서술에 담으면 좋습니다.

**셋째, 한계 인식이 함께 있습니다.** 보고서의 "한계1: 뉴스·보도 이후 소비자 신고가 따라 증가하는 미디어 효과로 인해 신고 급증은 실제 피해 증가만으로 설명이 불가능하다"는 서술은, 자기 분석의 약점을 스스로 지적한 것입니다. 이런 문장을 쓸 수 있는 지원자는 흔치 않습니다.

### 제안하는 서술 구조

```
문제 정의    신고 건수가 많다는 것이 곧 위험을 뜻하지는 않는다.
             그렇다면 어떤 신고 패턴이 실제 문제와 연결되는가?

담당 범위    팀 프로젝트: 운영 총괄 · 브랜드 사례 심층 분석 · 발표 수행
             본 저장소:   전 과정 재현·감사·개선안 설계 (개인 단독)

분석         심각 신고 상위 브랜드 선별
             → 연도별 신고 추이에서 급증 구간 식별
             → 해당 시기 규제기관 조치·보도자료와 대조
             → 두 사례에서 신고 급증과 실제 안전 이슈의 시점 일치 확인

한계         자발신고 데이터의 보고 편향. 보도 이후 신고가 늘어나는
             미디어 효과가 존재하므로, 시점 일치가 인과를 증명하지 않는다.

검증         재현 결과 확인된 지표 정의 문제와 개선안
```

### 서술 시 주의

| 쓰지 말 것 | 대신 |
|---|---|
| "통계적 이상치 탐지로 위험 브랜드를 발견했다" | "심각 신고 상위 브랜드를 선별해 시계열 추이를 확인했다" |
| "신고 급증이 제품 문제로 인한 것임을 확인했다" | "신고 급증 시기와 규제기관 조치 시점이 일치함을 확인했다" |
| "전체 신고의 43.9%가 심각 부작용이었다" | "전체 신고 64,517건 중 19.7%가 사망·입원·생명위협을 동반했다" |
| "산업군별 심각 부작용 비율을 분석했다" | (팀원 B 담당) 팀 분석 결과로 표기 |
| "발표 자료를 제작했다" | "발표를 맡아 수행했고, 사례 분석 파트를 구성했다" |
| "연령 파생변수를 설계했다" | (팀원 A 담당) 팀 분석 결과로 표기 |

**"시점이 일치했다"와 "원인이었다"는 다릅니다.** 보고서 본문도 이 구분을 지키고 있으므로, 저장소에서도 유지하면 됩니다.

| 발표 영상 (47MB) | 용량 · 실명 음성 노출 | 저장소에 포함하지 않음 |
| 원본 CSV (19MB) | 공개 데이터이나 용량 | FDA 원본 링크로 대체 권장 |

**원본 데이터 자체에는 개인정보가 없습니다.** CAERS는 FDA가 공개하는 데이터이며, 제품명 중 일부가 `REDACTED` 로 이미 익명 처리돼 있습니다. 다만 19MB로 GitHub 업로드 상한(100MB) 이내이므로 포함 여부는 선택 사항입니다. 재현성을 위해 포함하거나, FDA 공식 배포 페이지 링크로 대체할 수 있습니다.

## 6. 확정 사항과 잔여 확인

### 확정 (본인 확인 완료)

- 브랜드 선별: 산점도 우상단 영역을 **육안으로 판별**
- 급증 시기: 연도별 추이 그래프를 **육안으로 판별** 후 보도자료 검색
- 발표: 발표회 발표 담당 (영상 제작은 팀원 B, PPT 제작은 팀원 D)

### 잔여 확인

1. **사례 분석 코드 보유 여부** — 제출본 노트북에 브랜드별 연도별 추이 코드가 없습니다. 당시 쓰신 코드가 남아 있으면 재현 정확도가 올라갑니다. 없으면 재현 노트북(`02_improved_verification.ipynb` 8절)의 구현으로 대체합니다.
2. **인사이트·한계 서술 작성자** — 보고서 「인사이트 도출」의 한계1·2(미디어 효과, 자발신고 편향)가 본인 작성분인지. 사례 분석과 직접 이어지는 내용이라 함께 주장할 수 있는지 판단이 필요합니다.
