## 1. "전체 부작용 신고 중 약 43.9%"

**보고서 원문**

> 전체 부작용 신고 중 약 43.9%가 사망, 생명위협, 입원, 병원 방문과 같이 심각한 결과를 동반한 것으로 나타났다.

**재현 결과** — 43.9%는 정확히 재현됩니다. 다만 산출 경로에 세 가지 문제가 있습니다.

| 슬라이스 | 행 수 | 도넛 비율 |
|---|---:|---:|
| 사망 | 2,028 | 1.7% |
| 생명위협 | 5,274 | 4.3% |
| 입원 | 16,908 | 13.8% |
| 병원방문 | 29,652 | 24.2% |
| 비심각 | 68,820 | 56.1% |
| **분모(합계)** | **122,682** | |

- **분모가 전체 행 수(90,786)보다 31,896 많습니다.** 한 신고가 입원과 병원방문을 동시에 가지면 두 번 계산됩니다.
- **팀 자체 serious 정의(사망·입원·생명위협)에 없는 병원방문이 포함**됐습니다. 43.9% 중 24.2%p가 이 항목입니다.
- 단위가 "신고"가 아니라 "행"이며, 그마저 중복 계상됐습니다.

**중복 없는 재계산**

| 방식 | 값 |
|---|---:|
| 행 단위 심각도 | 24.20% (21,966 / 90,786) |
| 신고 단위 심각도 | 19.72% (12,720 / 64,517) |

**판단** — 이 문장은 사용할 수 없습니다. 대체 문장은 `reproduction_audit.md` 3절 참조.

## 2. "통계적 이상치 브랜드 발견"

**보고서 원문**

> Vit/Min 산업군 내 브랜드별 심각 부작용 비율 분석 중 통계적 이상치 브랜드 발견

**코드 확인 결과** — 브랜드 선별에 사용된 연산은 네 가지뿐입니다.

1. `query('total >= 20')` — 표본 하한
2. `nlargest(80, 'total')` — 신고량 상위 80개
3. `axvline/axhline(median)` — 중앙값 보조선. **그려지기만 하고 어떤 필터에도 사용되지 않음**
4. `주요브랜드 = [...]` — 라벨 표시용 하드코딩 목록 6~7종

IQR, z-score, Isolation Forest 등 **이상치 탐지 알고리즘은 존재하지 않습니다.**

**사후 검정 — 심각 비율 분포의 탐색적 IQR 비교** (보조 검증, 원본 분석에 미포함)

표본 수가 서로 다른 비율 간 비교이며 노출량을 반영하지 않으므로, **위험 브랜드 판정 기준이 아닙니다.**

| 브랜드 | 심각비율 | 전체 286종 IQR | Vit/Min 200종 IQR | robust z |
|---|---:|:---:|:---:|---:|
| HERBALIFE CELL ACTIVATOR | 86.6% | X | **O** | 2.93 |
| PLEXUS SLIM | 81.4% | X | X | 2.70 |
| **OXYELITE PRO** | 59.5% | X | X | 1.75 |
| **HYDROXYCUT** | 55.0% | X | X | 1.55 |

**심층 분석 대상 두 브랜드는 어떤 기준으로도 통계적 이상치가 아닙니다.** robust z가 1.5~1.75로 임계값 3.5에 크게 못 미칩니다. 브랜드별 심각 비율이 0%~100%로 넓게 분포해(Q1 4.4 / 중앙 19.4 / Q3 37.4) 55~60%는 상위권일 뿐입니다.

**당시 실제 선별 방식 (기록)**

사례 심층 분석은 팀 분석 종료 후 본인이 개인 수행했으며 해당 코드는 제출본에 없습니다. 브랜드 선별과 급증 시기 판단 모두 **그래프를 육안으로 확인하는 방식**이었음을 본인 확인으로 확정했습니다. 아래는 제출된 노트북 cell 16~17에 남아 있는 코드 기준 기록입니다.

1. 신고량 상위 80개 브랜드 산점도 작성
2. 중앙값 보조선으로 사분면을 시각적으로 구분
3. 우상단에 위치한 브랜드를 사람이 눈으로 선택
4. 선택한 이름을 리스트에 직접 입력해 라벨 표시
5. 그중 2종을 심층 사례로 서술

시각적 탐색 기반 사례 선정이며, 방법 자체는 부적절하지 않습니다. 문제는 표현입니다.

**판단** — "통계적 이상치 탐지"라는 표현을 사용하지 마세요. 실제로 한 일을 그대로 기술하는 편이 정확합니다.

## 4. 연령 구간 이원화

같은 발표 자료 안에서 두 그래프가 서로 다른 연령 정의를 사용합니다.

| 구간 | cell 10 함수 (파이 차트) | cell 13 pd.cut (스택바) | 차이 |
|---|---:|---:|---:|
| 영유아 | 2,964 | **2,007** | −957 |
| 청소년 | 3,007 | 3,058 | +51 |
| 성인 | 26,045 | 26,692 | +647 |
| 노인 | 20,890 | 19,937 | −953 |
| 합계 | 52,906 | **51,694** | −1,212 |

`pd.cut(bins=[0,6,20,60,120])` 은 기본값 `right=True` 이므로 구간이 `(0,6]` 입니다.

- **0세 1,212행이 어느 구간에도 속하지 않고 탈락**
- 6세는 영유아, 20세는 청소년, 60세는 성인으로 각각 한 칸씩 밀림

보고서에 기재된 4구간 수치(2,964 / 3,007 / 26,045 / 20,890)는 **cell 10 함수 기준**이며, 스택바 그래프는 다른 숫자 위에서 그려졌습니다.

## 6. '응급실' 슬라이스 누락

```python
'응급실': df['outcomes'].str.contains('EMERGENCY', na=False).sum()   # → 0
```

CAERS의 실제 표기는 `VISITED AN ER` 이라 `'EMERGENCY'` 매칭이 0건입니다. `data_counts[data_counts > 0]` 필터에서 조용히 제거돼 도넛 차트에 나타나지 않습니다.

한편 `'DOCTOR|VISIT'` 은 `VISITED AN ER`(12,890)과 `VISITED A HEALTH CARE PROVIDER`(20,158)를 **둘 다** 매칭해 29,652행이 됩니다(중복 3,396행). **응급실 방문이 '병원방문'에 흡수**된 상태입니다.

참고로 `'DOCTOR'` 단독 매칭은 0건입니다. CAERS 어휘에 `DOCTOR` 라는 단어가 없어, 정규식의 `DOCTOR|` 부분은 아무 역할도 하지 않습니다.

## 7. 신고 건수 단위 미표기

**모든 그래프가 행 기준**이며, 고유 신고 기준을 사용한 그래프는 없습니다. 원본 노트북에 `ra_report` 를 사용한 집계 자체가 존재하지 않습니다.

행 기준과 신고 기준의 차이가 특히 큰 지표입니다.

| 지표 | 행 기준 | 고유 신고 기준 | 차이 |
|---|---:|---:|---:|
| 전체 심각도 | 24.20% | 19.72% | −4.48%p |
| Dietary Conv 심각비율 | 45.07% | 40.89% | −4.18%p |
| Vit/Min 심각비율 | 34.77% | 30.91% | −3.86%p |
| Cosmetics 심각비율 | 13.98% | 14.70% | +0.73%p |

산업군 상위 10 순위도 바뀝니다. 행 기준 10위 `Vegetable Oils` 가 빠지고 `Beverage Bases/Conc/Nectar` 가 들어옵니다.

건강기능식품은 한 신고에 여러 제품을 함께 등록하는 경우가 많아(1.73배) 행 기준에서 과대 계상되고, 화장품은 신고당 제품 수가 적어(1.09배) 오히려 소폭 상승합니다.

**판단** — 수치 자체는 재현되므로 사용 가능하되, **"행 기준"임을 반드시 명시**해야 합니다. 명시 없이 "45.1%"라고 쓰면 "신고 100건 중 45건"으로 읽히는데 실제로는 40.9건입니다.

## 8. 외부 검증 결과

지시서 7번 항목을 FDA 공식 문서 기준으로 수행했습니다.

| 브랜드군 | FDA 조치 | 조치 연도 급증 | 최대 신고 연도 |
|---|---|---|---|
| OXYELITE | 2013-11-09 경고 및 회수 | 2012년 12행 → **2013년 100행** (8.3배) | **2013년** — 조치 연도와 일치 |

**시점의 일치는 인과관계가 아니라 외부 사건과의 시간적 대조입니다.**
